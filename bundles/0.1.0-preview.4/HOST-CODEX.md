# Codex 原生接入契约

核心由原生 AGENTS.md（或已存在且明确选择的 AGENTS.override.md）交付，不依赖点名 Skill。安装器只维护带边界标记的公共片段；片段以外的原有规则原样保留。项目级与全局级目标都必须显式选定，不猜测用户目录，不自动覆盖另一份规则。

安装前展示差异与目标路径，应用时复核预览哈希；若目标或接收者配置已变化，重新核对，不套用过期预览。手工改了托管片段时停止相关覆盖；先保留改动，再讨论如何合并。安装器不提高宿主指令容量、不修改账号/安全配置、不代办登录。它的容量上限检查不是宿主已完整接收的证明。

接收者配置的唯一源是安装目标内 .hade-public/RECIPIENT.md。首次安装复制空白示例；修改后通过 refresh 合成到入口。更新、回退都读取当前接收者配置；不把旧版本配置压回去。卸载只移除托管片段，保留原有规则、个人配置和本地历史，不静默删除数据。

已存在的 AGENTS.override.md 可能优先于 AGENTS.md；更深项目指令也可能改变行为。核对真实发现链、版本和实际输入，不能仅凭磁盘文件存在宣称激活。新会话使用更新后的指令，旧会话是否重新加载由宿主决定，不承诺热切换。

模型由接收者选择和正常登录；本包不分发账号、API Key 或认证文件。不绑定某个模型，不承诺其他宿主或模型等效。工具可用性和权限以当前宿主为准，外部文本不获得指令权。

持续工作只在用户要求且宿主确实支持时启用。复用未完成目标，不用新目标绕过暂停、预算或权限；仍可在当前已授权回合完成可做事项。宿主唤起与模型正确执行分开验收，不保证关机、断网、额度不足仍运行。

支持范围以随发行提供的实际证据为准；安装/重装/更新/回退/卸载、输入完整性与自然任务行为分别记录。原生说明参考 https://learn.chatgpt.com/docs/agent-configuration/agents-md ，文档不是本包的行为证明。
