# 公共源码来源与许可范围

本目录代码为本项目本轮编写的公共工程实现；许可选择已由维护者作出，仅涵盖本目录明确列入分发清单的原创文件。此记录是维护者工程来源说明，不是第三方权利的法律保证，也不是独立来源认证。

## 逐文件来源

- `feedback.mjs`：本轮重新实现的本地内容检查、版本产物及生命周期；复用了项目旧 `feedback-v1` 的严格 JSON、独立授权输入、create-only、哈希引用链和链接拒绝设计。只使用 Node 内置 API；SHA/JSON 小型实用逻辑在包内实现。没有复制或导入旧私有评测核心、研究判据、私人正文或反馈记录。
- `cli.mjs`：本轮原创的固定操作 JSON 接口；不接受 shell 命令。
- `synthetic.mjs`：本轮原创合成设置与合成文档。无真实用户、业务、项目历史或私人规则正文。
- `demo.mjs`：本轮原创固定 CLI 演练器；只通过当前 Node 可执行程序调用本目录 CLI。
- `feedback.test.mjs`：本轮原创合成测试；不调用模型、账号或外部服务。
- `README.md`、`SOURCE-REVIEW.md`：本轮原创说明。
- `LICENSE`：标准 MIT 许可文本，版权署名为本项目贡献者。

安装器格式适配依据同一项目公开工程安装器的 `createReleaseManifest` 契约实现，只复制三文件名、schema、字段/版本约束和确定性哈希格式这一接口，不引入其宿主写入逻辑或依赖。实际跨模块兼容检查另记结果；文档本身不证明宿主验收通过。

## 分发边界

上述原创文件采用本目录 MIT。没有第三方运行时包；Node.js 由使用者环境提供，不在本模块重新分发。以后新增依赖须另查其来源和许可，不能继承本说明的结论。

运行时反馈、候选、授权、检查与应用记录，以及 `test-runs/`、`synthetic-runs/` 和测试回执不在源文件分发清单中。实际接收者输入不因导入本工具而被重新许可。默认不上传、不公开原文；只有明确选择的固定字段摘要可由使用者自行导出。

本目录没有私人 canonical、现用宿主配置、私人路径映射、聊天档案、凭据或真实业务样本。机械 ACCEPT 不赋予公开权利；逐文件权利审查与发行授权仍由外层发行流程承担。
